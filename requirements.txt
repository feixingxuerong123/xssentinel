# Single source of truth for dependency versions: pyproject.toml.
#
# This file is NOT a second copy of that list -- it is a one-line delegation.
#   pip install -r requirements.txt
# is exactly equivalent to
#   pip install -e ".[dev,async,ast,api]"
#
# Why it stopped listing packages by hand: the hand-maintained copy pinned
# aiohttp / playwright / flask / esprima / pytest* as if they were core
# dependencies, so installing from this file produced a *different*
# environment than installing from pyproject (it dragged in the whole dev
# toolchain).  That is not version drift -- it is a semantic disagreement
# between two sources, and it is the reason this file now delegates.
#
# Playwright (headless browser confirmation) is deliberately NOT pulled in:
# it additionally needs `playwright install chromium`, and -- like CI --
# README documents it as a separate optional step.
-e .[dev,async,ast,api]
